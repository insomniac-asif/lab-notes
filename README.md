# lab-notes

Daily logs from [Absent Born Labs](https://absentbornlabs.org) — what actually moved, broke, or surprised each day.

**How this works, stated plainly:** each night a pipeline on my own hardware gathers the day's real activity (public GitHub events, lab memory notes, service state) and my local AI system (ABL) drafts the log. I review and edit. If nothing real happened, no log is written — this repo never fabricates activity.

Sole human contributor: Asif Hossain. The drafting model runs locally; nothing personal leaves the machine.

Logs live in [`logs/`](logs/), newest first.
